# Roadmap

- [ ] Support GNOME theme colors, including light, dark, high-contrast, and custom themes.
- [x] Add keyboard accessibility, including opening, closing, and navigating the Island without hover, plus accessible names for controls and metrics.
- [ ] Make the Expanded View responsive by stacking the calendar and metrics on narrow screens or when large text scaling is enabled.
- [ ] Add click-to-toggle and Escape-to-close behavior, and consider integrating the date area with GNOME's notification and calendar menu.
- [ ] Add preferences for refresh interval, graph history duration, expansion delay, visible metrics, date display, and hover versus click activation.
- [ ] Show an unavailable state instead of retaining stale CPU or RAM values when `/proc` reads fail.
- [x] Implement the [Tabbed Expanded View plan](TAB_VIEW_PLAN.md).
